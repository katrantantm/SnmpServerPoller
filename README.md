# SNMP Server Poller

Приложение для сбора информации о серверах через SNMP с экспортом данных в Excel.

## Требования

- .NET 8.0 SDK
- Microsoft Office (для работы с Excel)

## Установка

```bash
dotnet restore
dotnet build
```

## Использование

### Запуск с настройками по умолчанию (из appsettings.json)

```bash
dotnet run
```

### Запуск с указанием IP-адреса сервера

```bash
dotnet run -- <server_ip>
```

Пример:
```bash
dotnet run -- 192.168.1.100
```

## Конфигурация

Настройки находятся в файле `appsettings.json`:

- **Snmp.Community** - SNMP community string (по умолчанию: "tantm")
- **Snmp.Timeout** - таймаут запроса в мс (по умолчанию: 5000)
- **Snmp.Retries** - количество повторных попыток (по умолчанию: 3)
- **Excel.TemplatePath** - путь к шаблону Excel файла
- **Logging.LogLevel** - уровень логирования (Debug, Information, Warn, Error)
- **Logging.FilePath** - путь к файлу логов

## Собираемые данные

- Системная информация (описание, имя хоста, время работы, контакт, расположение)
- Сетевые интерфейсы (описание, тип, MTU, скорость, статистика)
- IP-адреса и маски подсетей
- ARP-таблица
- Таблица маршрутизации
- Информация о дисках (общий объем, использовано, процент)
- Загрузка процессора по ядрам
- Список запущенных процессов
- Оборудование и устройства
- Статистика протоколов (IP, TCP, UDP, ICMP, SNMP)
